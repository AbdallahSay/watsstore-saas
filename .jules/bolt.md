## 2024-05-18 - Cartesian Explosion in EF Core Navigation Properties
**Learning:** Including multiple collection navigation properties (like `Products`, `Categories`, `Orders`, etc.) on a single entity using `.Include()` generates a massive single SQL query with multiple JOINs. This leads to Cartesian explosion, causing huge data duplication in the result set, excessive memory usage, and poor database performance. The `DeleteStore` method in `AdminController.cs` fetched a Store with 5 related collections, creating a severe bottleneck during deletion.
**Action:** When using Entity Framework Core to fetch an entity along with multiple collection navigation properties, use `.AsSplitQuery()` before the `.Include()` calls. This instructs EF Core to generate separate, efficient SQL queries instead of one massive JOIN query, significantly improving performance and reducing memory overhead.
