## 2024-03-24 - Entity Framework Core Cartesian Explosions with Multiple Collections
**Learning:** When fetching an entity (like `Store`) that includes multiple collection navigation properties (like `Products`, `Categories`, `Orders`, etc.) using EF Core's `.Include()`, it results in a massive single SQL query that joins all tables together. This creates a "Cartesian explosion" (e.g., 1 store * 100 products * 10 categories * 1000 orders = 1,000,000 duplicated rows returned from the database). This leads to extremely high memory usage on both the database and the .NET server, and very slow query times. The default EF Core behavior for multiple collection includes is highly inefficient for complex entities.
**Action:** When using EF Core and including *more than one* collection navigation property on a query, always append `.AsSplitQuery()` to the LINQ expression. This instructs EF Core to generate separate SQL queries for each collection, significantly reducing the amount of duplicated data transferred over the network and processed in memory.
