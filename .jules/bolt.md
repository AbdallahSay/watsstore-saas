## 2024-10-25 - Entity Framework Core Cartesian Explosion with Multiple Includes
**Learning:** When using Entity Framework Core to fetch entities that have multiple collection navigation properties (like fetching a Store with its Products, Categories, Orders, etc.), chaining multiple `.Include()` calls results in a massive single SQL query with many `LEFT JOIN`s. This causes a "Cartesian explosion" where the database returns an exponentially large dataset containing redundant data, severely degrading performance.
**Action:** Always append `.AsSplitQuery()` to EF Core queries that `.Include()` more than one collection navigation property. This instructs EF Core to generate separate SQL queries for each collection, preventing Cartesian explosion, reducing memory consumption, and significantly improving overall backend performance.
