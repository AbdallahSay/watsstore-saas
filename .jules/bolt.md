## 2024-05-19 - Fix Cartesian Explosion in Backend EF Core Queries
**Learning:** Found multiple backend controller endpoints (e.g. `AdminController.DeleteStore`, `PublicStoreController.GetStoreBySlug`) using Entity Framework Core's `.Include()` to eagerly fetch multiple collection navigation properties (Products, Categories, Orders, etc.) simultaneously on the `Stores` entity. This configuration results in a single, massive SQL query that produces a Cartesian product, leading to severe performance bottlenecks and huge memory consumption on the backend due to duplicated data rows.
**Action:** Identified these instances and appended `.AsSplitQuery()` to the query chain. This instructs EF Core to issue separate SQL queries for each collection, thereby eliminating the Cartesian explosion and vastly improving backend response times for complex entity aggregations. Next time, always check for multiple `.Include()` calls fetching collections and proactively apply `.AsSplitQuery()` when fetching aggregations.
