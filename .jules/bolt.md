## 2024-03-24 - [Bulk Execution over Cascade Delete and Iteration]
**Learning:** Utilizing multiple `.Include` chains and `RemoveRange` in EF Core loads whole object graphs into memory (Cartesian explosion) which drastically reduces performance. Replacing this with `ExecuteDeleteAsync()` provides massive optimization as it deletes straight from the DB. However, because multiple `ExecuteDeleteAsync()` statements operate independently and immediately, they MUST be wrapped in a database transaction (`await _db.Database.BeginTransactionAsync()`) to guarantee the data integrity originally provided by `SaveChangesAsync()`.
**Action:** When performing bulk deletions on entities with lots of dependencies, avoid `RemoveRange()` and instead use `ExecuteDeleteAsync()` for each table, wrapping the entire block in a `BeginTransactionAsync()` transaction.
